# 地图编辑功能同步（来自307，2026-09-17）

本次仅同步导航界面的地图管理功能，不同步307的其他导航版本差异：

- 保存当前地图：二次确认、覆盖前备份、保存原路径，导航运行中禁止覆盖。
- 删除选中地图：二次确认、移入可恢复目录，当前使用和默认地图受保护，共享图像与航点库保留。
- 另存新地图：修正未知区域灰度205与free_thresh的对应关系，避免重载变成自由空间/白色背景。

原图备份位于地图所在目录的`.map_backups`；删除的地图位于同目录`.map_trash`。界面显示具体路径。手工修改只作用于导航栅格，不改变Cartographer历史轨迹。

同步时保留每台机器人的编号、话题、底盘控制、定位、规划、现有地图和航点数据。源码和实际安装入口均更新；Python界面无需编译C++或重新安装其他配置。重新打开控制中心即可使用，不重启当前导航/机械臂服务。

验证：AST检查所有非地图编辑函数保持不变，10项文件/界面测试，独立ROS域、仅本机的Nav2地图保存/加载像素一致性验证。
