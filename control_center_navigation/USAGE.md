# 原生导航界面使用说明

## 地图操作

- “浏览地图”：按住鼠标拖动，滚轮缩放。
- “设置导航目标”：在地图目标位置按下，向期望朝向拖动后松开，确认后发送 Nav2 目标。
- “设置初始位姿”：操作方式相同，确认后向 `/initialpose` 连续发布三次。
- “适应窗口”：恢复整图显示。
- “显示双激光”：控制前后激光点显隐。

## 全局定位

完整启动后会自动全地图搜索。右侧依次显示等待地图、等待双激光、匹配、确认或成功状态。

需要重新搜索时点击“重新执行全局定位”。

## 航点

- 双击航点或点击“导航到选中点”开始单航点导航。
- 点击“多航点导航”打开路线编辑器。
- 在左侧双击或点击“添加”可反复加入同一航点；右侧可以拖动、上移、下移、移除和清空。例如可以编排 `a → b → a → c → d`。
- 添加前可设置“新加入航点默认停留”；也可在右侧选择一个或多个队列项，修改“选中项停留”并点击“应用”。同一航点重复出现时可以分别设置不同停留时间。
- 如需反复执行整条路线，勾选“循环执行整个队列”，然后点击“开始多航点导航”。
- “保存当前位置”会将当前 TF 位姿直接写入本功能包源码中的 `config/waypoints.yaml`。

## 地图编辑

- 点击“描绘障碍”或“擦除障碍”，按住地图左键连续编辑；右键仍可拖动地图。
- “笔刷半径”可设置为 `5～100 cm`。
- 编辑错误可使用“撤销”“重做”，或点击“丢弃修改”恢复当前已加载地图。
- 输入一个从未使用过的名称并点击“另存新地图”。同名文件会被拒绝，旧地图不会覆盖。
- 在地图库下拉框选择原地图或编辑地图，停止当前导航后点击“加载选中地图”。
- 加载成功后 `/map`、AMCL 和 Nav2 会切换到所选地图，并自动重新执行全局定位。

## 底盘控制

- `W/S`：前进/后退。
- `A/D`：左转/右转。
- `Q/E`：左移/右移。
- 支持组合按键，例如按住 `W+A` 前进左转、`W+D` 前进右转；相反方向键同时按下时相互抵消。
- `X`：急停。
- 空格：取消由地图界面发送的导航目标。

只有按住按钮或按键时才持续发布速度，松开、窗口失焦或关闭界面都会停车。
