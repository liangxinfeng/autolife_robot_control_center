# 307 到点精调收敛调整（2026-09-08）

- 所有目标先 Nav2，2m 内直接伺服仍关闭。
- 末端精调中，odom 与 map 的位置均在 4cm、朝向均在 0.05rad 内时立即发零速，连续稳定 max(settle_time, final_map_settle_time) 后完成；当前为 0.5 秒。不再叠加两轮等待。
- 位置满足径向到达精度后转入朝向调整，避免继续追逐更紧的单轴 2cm 阈值。
- XY 比例增益 0.9→1.2，Yaw 1.2→1.5。最高线速度 0.16m/s、角速度 0.45rad/s、加速度及安全检查不变。
- 误差超限、障碍等待、停用或新目标会清除稳定计时。保留总超时、不收敛失败、同航点重试及安全停止；不会伪报到达。
- 50项离线测试通过，包括原有避障、取消交接、人工目标和几何检查。没有实机移动测试；部署不重启当前会话，需要用户安全退出后重新打开。

验收：同一航点从不同方向接近，记录开始精调至到达的耗时与最终误差；有人挡路时确认停车而不是误报成功。实际精度受 AMCL、里程计和机械误差影响，参数容差不是物理精度保证。
