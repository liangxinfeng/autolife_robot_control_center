# 307 导航地图保存与删除（2026-09-17）

- **保存当前地图**：覆盖当前已加载地图（不是下拉框预选地图），保留 YAML/图像原路径、坐标原点、分辨率与航点库。确认后自动备份到该地图目录的 `.map_backups`；导航服务就绪时重新加载，否则下次启动生效。导航运行中不能保存。
- **另存新地图**：保留原图，禁止重名覆盖。修正灰度205未知像素与阈值不一致的问题，重载后仍为未知区域，保持深色背景，而不是变成自由空间。
- **删除选中地图**：需要二次确认。当前使用或默认地图不可删除；将地图 YAML、独占图像和同名 pbstream 移至同目录 `.map_trash`，可人工移回原目录恢复。共享图像不删除，航点库保留。不递归删除任何目录。
- 仅修改导航栅格；手工涂改不会同步改写 Cartographer 的历史 pbstream 轨迹，后续增量建图不能假设历史轨迹已包含手工修改。

对旧编辑器生成且仍带 `# edited by control_center_navigation` 标识、阈值为0.25的地图，备份 YAML 后修正为0.196，图像原文件不变。没有原始未知像素的地图不能凭空恢复未知区域。

离线文件测试覆盖 PNG/PGM 覆盖备份、坐标一致性、写入失败回滚、删除恢复、活动地图保护、共享图像保护，以及未知/空闲/障碍重载一致性。独立 ROS Domain 88、仅本机的 Nav2 map_server 加载测试核验实际 OccupancyGrid 全部像素一致，不连接机器人控制域、不发送运动命令。
