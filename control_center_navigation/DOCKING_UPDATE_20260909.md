# 306 回充更新（2026-09-09）

适用：control_center_navigation，控制中心与 vr306nav 共用。充电桩航点必须是机器人已经接触充电时保存的本体位姿；没有修改现有航点。

流程：Nav2 到桩前 → 原末端位姿精调 → 低速闭环倒车 → 电池反馈确认充电。预对准点由接触位姿沿机器人前方偏移 0.55 m 得到，精调通过才交给 DockRobot，避免再次使用宽松的 staging 导航。

倒车改进：
- 保留入桩控制器转向与停止指令，移除强制直退、强制最低倒车速度。
- 最后一段将接触目标锚定到 odom，避免 AMCL 跳变带着对接目标移动。
- 倒车速度 0.025～0.07 m/s，角速度上限 0.12 rad/s；碰撞检测仍开启。
- 横向偏差超过 0.06 m、角度超过 0.14 rad、越过接触位姿 0.03 m 仍未充电、TF/电池反馈过期时停止。等待入桩 Action 真正终止后才允许重新发起导航。
- 需新鲜电池反馈；不把仅到达地图坐标误判成充电成功。

参数：config/voice_feedback.yaml 的 dock_prealign_enabled、dock_staging_distance、dock_max_lateral_drift、dock_max_heading_drift；config/docking_params.yaml 的 controller 速度和超时。

验证：离线方法测试及导航回归测试，不代表已验证真机对接精度。安全退出并重启导航后，先有人监护进行单次回充测试，记录入桩轨迹和充电反馈。没有相对充电桩传感器，里程计打滑、保存位姿误差或桩移动仍可能导致对接偏差；不可保证仅凭地图位姿百分百对准。
