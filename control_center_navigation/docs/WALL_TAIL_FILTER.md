# 283 贴墙弱回波拖尾过滤（2026-09-23）

## 范围与原理

在现有逐雷达 `laser_filters` 链中，自体过滤之后增加一个无状态 C++ 插件。
只检查无回波区域旁的短弱回波尾部：前方必须有足够长度、强度及直线一致性的墙段，尾部必须弱、短、连续且向传感器弯曲。证据不足原样通过。

- 不使用“离地图墙近就删除”的规则；不整体提高强度阈值。
- 缺失的光束不插值；允许尾部内部最多3个缺失采样，但仍检查实际点距。
- 40厘米内的传感器回波、独立弱物体、较大突入、强回波、缺失强度信息均不按该规则处理。
- 被拒绝点置为 NaN，不转换为 infinity，不新增清空射线。
- 没有地图缓存或多帧积累；输出时间戳、角度、强度和保留点的距离完全不变。
- 参数与强度尺度来自283当前雷达数据，**不要未经验证复制到不同型号雷达**。

## 接线

原始前/后雷达 -> 已有严格车身内部过滤 -> WeakWallTailFilter -> `/navigation/front_scan` 和 `/navigation/rear_scan` -> 局部/全局障碍层。

导航UI显示上述同一输入，不只是视觉隐藏。原始话题仍可用于诊断；AMCL、建图、重定位、车身55×55厘米和终点容差不变。
`front_display_scan_topic` / `rear_display_scan_topic` 可指定显示话题；原始 `front_scan_topic` 继续用于机器人身份解析。

## 验证与限制

- 18个纯C++几何回归案例覆盖直墙、近障碍、弱物体、缺强度、大突出、断裂/圆形物体等。
- 两段录制数据共903帧离线回放：一段430帧完全不变；另一段识别出满足条件的弱尾点。没有逐点人工真值，不能把其余点直接宣称为全部真障碍。
- 隔离ROS域89下实际过滤链186帧，输出与纯算法+自体过滤结果逐点一致；测得中位耗时约0.62ms。
- 尚需实机确认贴墙停靠改善与真实障碍保留；几何和强度不能在所有材质/角度下唯一判断真假障碍。
- 严格条件有意允许部分可疑回波残留；**不保证消除所有弧线或所有到点失败**。原有代价图中的旧标记需要正常观测清除，重新启动导航会建立新代价图。
- 暂停本插件：`config/navigation_self_filter.yaml` 中 `weak_wall_end_tail.params.enabled: false`，更新安装配置并重新打开导航。不要改动已有自体过滤或关闭障碍层。

现场首次复测应低速、人员避开路径、急停可及。此补丁不含自动发起动作或重启厂商服务。
